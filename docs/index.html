🔔

Notification detection

How it works

Three steps, then you never type a code by hand again.

1

Grant 5 permissions

SMS, send notifications, read notifications, display over other apps, and battery exemption. The big start button stays dimmed until all five are granted.

2

Start tracking

Tap the start button at the top. A "You're ready" notice appears, and a test notification arrives 10 seconds later so you can leave the app and see it work.

3

Drag the code

When a code arrives, the bubble pops up. Drag the code onto the field to paste it. If a field refuses drops, tap the code to copy it instead.

Questions, answered

Does CodeBubble upload my codes anywhere?

No. It has no internet permission. Codes are detected on your device, copied to your clipboard, and kept in a local history. Nothing leaves your phone.

What if a field refuses the drop?

Some fields (banking apps, some web forms) reject drag-and-drop. Tap the code in the bubble to copy it, then paste normally. That always works.

Is it on Google Play or F-Droid?

Not yet. Right now it is distributed from GitHub. The APK here is signed with the same key as every previous version, so future updates install over it.

Which Android versions work?

Android 8.0 and newer. On Android 15+, an extra note with two copyable ADB commands appears for enhanced notifications.

How do I automatically copy OTP codes on Android?

CodeBubble detects verification codes from SMS and app notifications and copies them to the clipboard automatically, so you can paste them without typing. The draggable bubble gives you the code on screen as well.

Is there an app that lets me drag a verification code into a field?

Yes. CodeBubble shows a draggable bubble with the code. Long-press the code and drop it directly onto the text field to paste it. If a field refuses drops, tap the code to copy it instead.
